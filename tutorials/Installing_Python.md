## Installing Python and a Code Editor

To use this toolbox, you will need **Python** and a way to run Python code (an **interpreter**).

Below are two beginner-friendly ways to get started.

---

### Option 1: Install Python Directly (Simplest)

#### 1. Download Python

Go to the official Python website:

https://www.python.org/downloads/

Click **Download Python** for your operating system.

---

#### 2. Install Python

Run the installer and follow the instructions.

**Important:**  
When installing on Windows, make sure to check the box:
- Add Python to PATH

Then click **Install Now**.

---

#### 3. Verify the Installation

Open a terminal:

- **Windows:** Command Prompt or PowerShell  
- **Mac/Linux:** Terminal

Type:

```bash
python --version

#If Python installed correctly, you should see something like:
Python 3.11.6
```

#### 4. Install a Code Editor (Recommended)

While Python can run directly in the terminal, code editors help you write, edit, and debug code easily in various programming languages.

Here are some popular, free options:

- [Visual Studio Code (VS Code)](https://code.visualstudio.com/download)
- [Spyder](https://www.spyder-ide.org/download)
- [PyCharm Community Edition](https://pycharm-community-edition.en.softonic.com/)
  

## Option 2: Install a Python Distribution

Another option is to install a Python distribution. These packages include Python along with useful tools and libraries for scientific computing, data analysis, and machine learning.

Common distributions include:

- [Anaconda](https://www.anaconda.com/download/success?reg=skipped)
- [Miniconda](https://www.anaconda.com/download/success?reg=skipped)
- [Mambaforge/Miniforge](https://github.com/conda-forge/miniforge)

These distributions often include helpful tools such as:
- Package managers (to easily install libraries)
- Scientific Python libraries
- Development environments (e.g., VS Code, Spyder, Jupyter Notebook)
