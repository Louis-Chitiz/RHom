## Forking and Cloning RHom

If you want to use or modify this project locally, the typical workflow is to **fork** the repository to your GitHub account and then **clone** it to your computer.

---

### 1. Fork the Repository

Forking creates your own copy of the repository on GitHub.

1. Go to the repository page:  
   `https://github.com/Louis-Chitiz/RHom`

2. Click the **Fork** button in the upper-right corner of the page.

3. GitHub will create a copy of the repository under your account:
   `https://github.com/YOUR_USERNAME/RHom`

You can now make changes to this copy without affecting the original repository.

---

### 2. Clone the Repository

Cloning downloads the repository from GitHub to your local machine.

You can do this either with [**Git**](https://git-scm.com/install/) or [**GitHub Desktop**](https://desktop.github.com/download/).

---

#### Option A: Clone Using Git (Command Line)

1. Go to **your fork** of the repository (i.e., `https://github.com/YOUR_USERNAME/RHom`)
   
2. Click the green **Code** button.

3. Copy the repository URL (HTTPS).

4. Open a terminal (Mac/Linux) or **Git Bash** (Windows).

5. Run:

```bash
# Open the folder where you want the repository
cd path/to/folder

# Clone the repository
git clone https://github.com/YOUR_USERNAME/RHom.git
```

#### Option B: Clone Using GitHub Desktop (Beginner Friendly)
If you prefer a graphical interface:

1. Install GitHub Desktop if you don't already have it: https://desktop.github.com/
   
2. Open GitHub Desktop and sign into your GitHub account.

3. Click File → Clone Repository.

4. Go to the GitHub.com tab.

5. Select YOUR_USERNAME / RHom from the list.

6. Choose a local folder where the repository should be saved.

7. Click Clone.

8. GitHub Desktop will download the repository and open it automatically.
